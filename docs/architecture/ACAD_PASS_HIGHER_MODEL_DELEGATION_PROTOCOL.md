# ACAD_PASS — Higher-Model Delegation and Cost-Control Protocol

Version: 1.0.0 · Adopted: 2026-10-03

## Purpose

Higher-model access is limited and expensive. Use it for tasks where stronger strategic reasoning materially improves ACAD_PASS, not for routine implementation that the implementation agent can perform correctly.

## Roles

**Higher model:** Chief Architect, Research Director, Strategic Reviewer, Red-Team Consultant.

**Implementation agent:** research collection, coding, repository changes, test execution, experiment execution, measurements, routine debugging, evidence preservation, documentation, and preparation of review packets. The implementation agent may propose improvements; it must escalate changes that alter architecture, scientific contracts, evaluation populations, safety gates, or protected evidence boundaries.

## Default delegation rule

Before doing substantial direct work, the higher model asks whether the task genuinely requires higher-level synthesis, architecture judgment, difficult brainstorming, independent review, or high-stakes scientific interpretation. If not, it issues an implementation packet and waits for returned evidence.

Routine work delegated by default includes code, scripts, GitHub operations, tests, ordinary debugging, data inventory, cost/latency accounting, routine literature collection, repository inspection, source extraction, and execution of already-authorized protocols.

## Higher-model direct work is justified for

- master architecture and architecture pivots;
- benchmark/experiment design where methodological error could invalidate conclusions;
- deep synthesis across conflicting or rapidly changing evidence;
- major research-direction brainstorming;
- independent review of frozen results;
- go/no-go decisions before opening data, changing safety gates, or beginning major phases;
- high-stakes interpretation of unexpected failures or contradictory evidence.

When direct work is justified, the higher model should state the reason briefly.

## Research workflow

Default sequence: implementation agent collects current papers, official documentation, repositories, datasets, competing systems, and contradictions; returns a compact research evidence packet; higher model performs the difficult synthesis and decision. Higher-model independent deep research remains appropriate when evidence is incomplete, conflicting, recent changes may alter architecture, or independent verification is itself required.

## Execution and return packets

A delegated execution packet should define objective, inputs, files, exact tasks, research, tests, metrics, invariants, forbidden actions, stop conditions, expected evidence, return summary, and early-escalation conditions.

The implementation agent returns a compact higher-model review packet with phase status, key metrics, failures, deviations, evidence links/commits/hashes, cost, unresolved questions, its recommendation, and only the questions requiring higher-model judgment. Raw logs are referenced rather than pasted unless needed.

## Stop-after-delegation rule

After issuing an execution packet, the higher model stops that strategic workflow and waits for actual returned evidence. It may outline possible next branches but does not spend substantial effort designing them as if execution had succeeded.

## Permanent optimization objective

Maximize final ACAD_PASS quality per unit of higher-model use. Cost control must remove wasteful higher-model execution, never scientific rigor.
