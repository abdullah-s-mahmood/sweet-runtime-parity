# Source and license metadata

The 150 target annotations are a fixed selection of Nahw-Passage records from the locally retained source `phase1/iteration4/source/Nahw-Passage.json`. Original item indices and passage IDs are in `DEVELOPMENT_TARGETS.jsonl`. The repository's license is Apache-2.0; research users should cite Mubarak, Hawasly, and Mohamed, *Nahw*, EACL 2026, DOI 10.18653/v1/2026.eacl-long.296. Source: https://github.com/qcri/nahw-arabic-grammar-benchmark

Each reference here applies one published target correction by exact replacement. This derived paragraph may retain other errors and is not a fully corrected human reference. The source passage is repeated for several target records. The 12 scientific cases were written by the project and explicitly carry `NON_HUMAN_GOLD`.

`SEALED_EXCLUSION_AUDIT.json` lists only excluded passage identifiers and hashes of prior sealed files; no sealed text was transferred.
