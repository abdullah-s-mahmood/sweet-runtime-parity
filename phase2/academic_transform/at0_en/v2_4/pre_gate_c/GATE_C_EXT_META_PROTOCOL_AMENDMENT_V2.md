## 3. Adapter boundary

Adapters may:
- freeze/select eligible records;
- serialize, rename and normalize transport fields;
- preserve or convert offsets deterministically;
- perform preregistered arithmetic/format operations;
- apply only mappings whose semantic equivalence is already established;
- compute metrics after predictions are frozen.

Adapters may NOT:
- resolve entailment, reference, ambiguity or scientific meaning;
- generate semantic claims or relations required for success;
- repair negation, ownership, scope, equations or relation binding;
- retrieve/select evidence using gold rationale to improve prediction;
- infer missing labels;
- suppress required coverage.

A deterministic rule is still an invalid semantic augmentation if it adds capability needed for success.

## 4. Hard Gate H1 — Scientific transformation fidelity

H1 is defined by REQUIRED FUNCTIONS, not a minimum count of dataset names.

Both functions must be covered:

### H1-S — Output support/factuality
Every evaluated output statement within scope must be supported by the allowed source/context under the relevant human/expert gold contract.

### H1-C — Required-content preservation/completeness
Required source content designated by the valid human/expert task contract must remain preserved at the granularity actually supported by that benchmark.

Support and completeness are separate constructs.

### Candidate pool

Direct scientific transformation candidates:
- CLEF SimpleText 2025 manually annotated real-system outputs;
- eligible PLABA/TREC PLABA human judgments.

Conditional substitutes/gap fillers:
- FactPICO for PICO/finding preservation and factuality;
- FaReBio for source-faithfulness/support.

Diagnostic by default:
- LongSciVerify.

### H1 package rule

Use the minimum non-redundant set that jointly covers H1-S and H1-C with adequate source-cluster evidence.

If SimpleText + eligible PLABA/TREC jointly cover both functions under their actual labels, no extra mandatory dataset is required.

If one function remains uncovered, add the smallest valid substitute that closes that specific gap.

No benchmark counts merely because it has a different name.

## 7. Hard Gate H4 — Independent metamorphic validation

H4 tests ACAD_PASS-specific relations using oracle conditions independent of:
- verifier outputs;
- extractor decisions;
- semantic rules being tested.

### REJECT-guaranteed families, subject to applicability predicates
- owner/value swap;
- group-label swap;
- explicit negation flip;
- unsupported modality strengthening;
- association -> causation;
- citation-owner swap;
- equation coefficient-variable swap;
- denominator change;
- baseline/comparator change;
- temporal/scope change;
- critical qualifier deletion;
- unsupported critical insertion.

### PASS-preserving families
Only under explicit proof conditions:
- proposition-preserving split/merge;
- safe clause reorder without referential change;
- format-only transformation;
- frozen safe synonym substitution;
- citation-style change preserving ownership.

### REVIEW
Allowed only where:
- two or more materially distinct critical interpretations remain possible under allowed context;
- the relation cannot be resolved;
- no higher-precedence REJECT or INVALID condition applies.

### Anti-degenerate controls
Matched cases must prevent:
- PASS-all;
- REJECT-all;
- REVIEW-all;
- lexical shortcut success.

### Oracle validity
Every family must freeze:
- applicability predicate;
- independent semantic justification;
- transformation;
- expected outcome;
- prohibited edge cases;
- source-cluster identity;
- seed if relevant;
- exclusion rule.

Invalid oracle cases cannot be counted as hard-gate successes.

## 9. Evidence-location vs evidence-support

Two different properties must be audited:

1. reference/location correctness:
   the cited span/reference points to the intended source material;

2. semantic-support correctness:
   the cited material actually supports the decision/relation.

Reference matching alone is insufficient proof of semantic support.

Before execution, each applicable hard track must freeze:
- which decisions are auditable;
- audit denominator;
- audit coverage;
- semantic-support adjudication rule.
