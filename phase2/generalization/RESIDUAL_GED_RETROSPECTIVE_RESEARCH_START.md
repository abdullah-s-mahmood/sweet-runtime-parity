# Residual GED Retrospective Replication — Research Start

Date: 2026-09-29

The immediate research question is no longer whether voting improves Arabic GEC generally. It is whether post-edit residual error detection can discriminate locally plausible but incomplete repairs.

The replication therefore keeps the target-clean rule frozen and tests cross-slice consistency instead of adding voters or thresholds.

Relevant directions already established in the current Phase 2 research ledger:
- edit-level voting can reduce over-correction but cannot guarantee repair completeness;
- multi-pass/post-edit evaluation is useful only when the secondary signal is sufficiently independent;
- correction acceptability requires sentence/context validity, not merely local edit plausibility;
- Arabic grammar remains context-sensitive, so REVIEW remains a first-class outcome.

No literature claim is used to tune the retrospective rule.
