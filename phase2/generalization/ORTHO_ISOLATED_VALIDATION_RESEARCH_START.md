# ORTHO_ISOLATED Fresh Validation — Research Start

Date: 2026-09-29

Fresh literature check reinforces the design: Arabic GEC benefits from local edit representations, but Arabic morphology remains difficult; edit-level voting can reduce over-correction without proving contextual correctness; robustness work shows context perturbations can flip edit validity; Arabic dependency parsing offers a later structured-syntax escalation if morphology-preserving isolation fails.

This phase therefore tests the simplest falsifiable claim first: whether the already-frozen narrow orthographic/common-noun/isolated lane generalizes unchanged. No new parser or verifier is added before that test.
